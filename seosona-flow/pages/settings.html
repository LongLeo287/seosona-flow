Smart Features
Cross-project ref images
Ref images from albums or other projects are automatically re-uploaded to the current project when used. No manual download and upload needed.
Auto-recover ref images after reload
When you reload the Flow page, missing ref images are automatically found by file_name (UUID) or re-uploaded from cache. The system checks 5 layers before reporting an image as lost.
Smart image cache
Ref images are cached for 24h after a successful upload. If the original image is deleted from Flow, the system re-uploads it from cache automatically.
Album stores originals locally
Album images store the original blob on your device, independent of Google Flow. Even if you delete images on Flow or switch projects, album images remain usable.
Cross-project collision protection
When switching projects, the system detects ref images from the old project (orange/red border warning) and re-uploads the correct image instead of using the wrong one at the same position.

Upload/capture images store blobs in IndexedDB, auto-deleted after {days} days.

Flow images use Google CDN URLs, only accessible with the account that created them.

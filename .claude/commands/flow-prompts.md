argument-hint: <từ khoá>

Tìm prompt qua MCP `seosona-flow-local`:

1. Gọi `search_prompts` với `query: "$ARGUMENTS"`, `limit: 10`.
2. Liệt kê mỗi kết quả: `id` · `title` · tags · trích `text` (1–2 dòng).
3. Nếu prompt có `{placeholder}`, gợi ví dụ điền (skill interview-to-spec / PromptSlots) để user dùng ngay.
